基于 RK3562 的 AI 实验室安全监控与设备控制系统，集成 USB 摄像头、YOLO/RKNN NPU 推理、Qt 可视化界面、异常检测与硬件联动控制。
# 基于 RK3562 的 AI 智慧实验室安全监控与设备管控系统

## 项目简介

本项目基于 Rockchip RK3562 嵌入式 AI 平台开发，实现一个集 **AI视觉检测、Linux嵌入式开发、Qt可视化界面、硬件控制、网络通信** 于一体的智慧实验室安全监控系统。

项目目标是利用 RK3562 自带 NPU 加速能力，在边缘端完成实时目标检测与异常行为分析，实现无需依赖云端的本地 AI 推理，并结合 GPIO、串口等硬件接口，实现检测结果与实际设备控制联动。

本项目将持续开发并开源，记录从 Linux 系统搭建、摄像头驱动、AI模型部署、Qt界面开发到完整智能终端实现的全过程。
